# X Pulse · 商机雷达

Manifest V3 浏览器扩展。浏览 X 时自动显示账号粉丝数；在帖子详情页手动扫描当前标签页已加载的评论，找出与当前产品匹配的需求。支持 Chrome / Edge 111+，原生 JavaScript，零第三方运行依赖。

## 安装

1. 运行 `node build.cjs`，或使用仓库已构建的 `dist/`。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，指向 `dist/`。
3. 刷新已打开的 X 页面。

## 使用

1. 点击扩展图标，在“我的产品”填写名称、简介、解决的问题、目标客户和核心能力，启用并保存。关键词、排除关键词、预算范围可选。
2. 在“AI 设置”填写 OpenAI 兼容服务的 Base URL、API Key 和模型，点击“测试连接并授权域名”。默认 Temperature 为 0.2、超时为 30 秒。Base URL 支持 HTTPS 或本机 HTTP，自动拼接 `/chat/completions`。
3. 打开 X 帖子详情页，等评论加载后点击原帖附近的“扫描评论商机”。每次最多处理 100 条规则命中的候选评论，每个 AI 请求最多 10 条；点击“分析下一批”继续。若评论还未加载到当前标签页，先在 X 页面正常滚动加载。
4. 扫描进度和本帖统计显示在原帖附近。默认只在高意向评论旁显示标记；Popup 中可改为中高意向或全部。点击标记查看判断依据并收藏，或在 Popup 的“我的商机”中搜索、筛选、排序、查看详情、备注、加标签及删除。

粉丝徽标、账号悬停卡片、独立的账号收藏与 CSV/JSON 导出继续可用。旧版推文指标徽标、互动率高亮和关键词过滤已移除；存储中的旧配置字段会被忽略，账号收藏数据不会被删除。

## 判断与数据边界

- 只复用 X 页面本身已经产生的响应，不主动请求 X API，不后台轮询。扫描仅由用户点击触发；只收集能通过回复关系确认属于当前讨论串的直接回复和楼中楼回复，排除原帖及引用帖。
- 本地规则先排除闲聊、纯表情和明显广告，再挑选需求、工具、痛点或商业意图评论。规则只用于初筛，最终判断由用户配置的 AI 服务完成。
- AI 仅收到原帖、必要的回复上下文、评论、公开作者指标和当前产品配置。不会发送 Cookie、请求头、X Token 或完整 X 响应。API Key 保存在扩展本机存储中，仅由后台发起 AI 请求使用。向 AI 服务发送内容前，请确认其数据处理条款符合你的需要。
- AI 必须返回结构化 JSON 和逐字可核对的证据。商机强度在本地按意图 40%、痛点 25%、商业信号 20%、紧迫度 15% 计算；优先级按商机强度 60%、产品匹配度 40% 计算。未明确提及的预算保持 `unknown`。40 分以下及非商机结果不进入商机列表。
- 分析结果、收藏、备注、标签和分析缓存只存储于本机。缓存依据包括评论文本、产品配置、模型和接口地址；改动后会重新分析。单批失败会显示错误，允许再次点击继续，失败批次不会自动重试。
- 仅在测试 AI 连接时申请配置域名的可选主机权限。Manifest 声明 `https://*/*` 作为可选范围以支持用户自选兼容服务；实际请求只针对用户填写的域名，不申请全站必需权限。

## 开发与测试

```bash
node build.cjs
node --test tests/*.test.cjs
```

`src/page/bridge.js` 在页面主世界观察 X 已有的 fetch/XHR 响应并做字段白名单过滤；`src/shared/transport.js` 在隔离环境中解析用户与推文。`src/content/opportunity-ui.js` 管理帖子扫描入口和评论标记；`src/background.js` 串行化本地写入及 AI 请求。`src/shared/opportunity.js`、`ai-client.js`、`opportunity-store.js` 分别实现规则与评分、AI 请求、本地存储。`dist/` 是可加载的构建产物，源码修改后需要重新构建。

自动测试覆盖回复归属、规则、AI 结果校验、评分、超时、权限拒绝、缓存、商机增删改、100 条上限、虚拟列表复用，以及原有粉丝徽标与账号收藏。当前自动测试为 79 项。真实 X 页面结构可能变化；如扫描按钮或评论标记未出现，可打开诊断信息并检查当前帖子是否已被页面加载。
